# Bookmark Manager Roadmap

A look at planned improvements and known risks for Mona's Bookmark Manager App.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search & filter bookmarks | 🚀 Feature | High |
| Management | Edit a bookmark | 🚀 Feature | Medium |
| Organization | Tags or folders | 🚀 Feature | Medium |
| Portability | Import & export bookmarks | 🚀 Feature | Medium |
| Reliability | Duplicate slugs on re-add | 🐞 Bug/risk | Medium |
| Validation | Empty-URL validation gaps | 🐞 Bug/risk | High |
| Persistence | Bookmarks lost when localStorage is cleared | 🐞 Bug/risk | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: medium
- 🏷️ Tags or folders — priority: medium
- 📦 Import & export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL validation gaps — priority: high
- 🐞 Bookmarks lost when localStorage is cleared — priority: medium
